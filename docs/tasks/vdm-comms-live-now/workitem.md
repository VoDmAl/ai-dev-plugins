# vdm-comms: живой now.md — сборка из домов по владельцу пункта, вместо листа дня

> Бриф hq `live-now-comms` (2026-09-28): решение владельца после грила — лист дня
> `signals/YYYY-MM-DD.md` делится на живой `now.md` (состояние) и датированные новости. Наша часть —
> сборка `now.md` из домов; новости, календарь и строку хука делает echelon. Заведён в `ready`: в
> работе скилл писем.

## Назначение

**Цель** (ТЗ §2, §4, §6). `signals/now.md` собирается из домов проекта (`pending-paths`,
`pending-sections`, «Мои задачи» echelon):
- первая строка — ссылка на инструкцию проекта «как работать»;
- блоки: «твой ход» (владелец пункта — «владелец») · «сегодня и завтра» (от echelon) · «ведёт штаб /
  соседи» (остальные, с датой пересмотра);
- мимо фильтра, сразу в «твой ход» с пометкой «факты собираю»: личные обращения к владельцу, сроки его
  обещаний, исходящее от его имени (черновики `comms/*-out*.md` без `sent:`);
- подъём: пункт соседа с прошедшей датой — в «твой ход»;
- номер пункта — метка блока Obsidian `^id` на строке в доме; `now.md` ссылается `[[файл#^id]]`;
- пересборка без модели; реплики владельца `>> …` в файлах собираются для строки хука echelon.

**Ограничения.** Сразу во всех проектах echelon: hq, command-center, program. Стык с
echelon (календарь, «Мои задачи», счётчики для строки хука) договариваем напрямую.

**Критерий успеха** — приёмка ТЗ §7 в hq, пункты 1–3 и 6: `now.md` из домов с инструкцией в
первой строке; закрытый в треке пункт исчезает после пересборки; просроченный пункт соседа поднят;
реплика `>>` видна сессии первой.

## Текущая модель

Состояние на 2026-09-28, до начала работы:

- **Что уже есть.** `comms-pending.py --owner` делит открытые пункты домов по владельцу; черновики без
  `sent:` плагин видит (`unsent_drafts`, с 0.6.6 — и `sent: false`). Меток `^id`, файла `now.md`,
  реплик `>>` в плагине нет.
- **Главное противоречие — не решено.** ТЗ хочет пересборку `now.md` после каждого прохода echelon и
  после правки дома в сессии, а метки `^id` — «поставить, если её нет», то есть запись в файлы треков.
  Плагин с `comms-plugin` DL #9 файлов проекта сам не пишет: хук сигналит, пересборку запускают по
  просьбе (`/vdm-comms:index`). Нужен DL: исключение для `now.md`, или пересборка — команда, которую
  зовут echelon (`after_pass`) и сессия.
