# Дрейф синтеза гасится прикосновением к самому синтезу

> Найдено 2026-09-22 на себе: я переписал `docs/model/suite.md` содержимым, идентичным
> прежнему (правка не применилась — не совпал якорь), и живой сигнал дрейфа **замолчал**.
> Это ровно тот ход, который документ `docs-distill` называет запрещённым для человека, —
> и он оказался доступен любому инструменту, который просто сохраняет файл.

## Назначение

**Цель.** Сделать так, чтобы дрейф синтеза нельзя было погасить, не изменив содержимого:
вердикт выносит git, значит и отбор кандидатов не должен зависеть от того, когда файл
трогали.

**Ограничение.** Не потерять то, ради чего появился контент-фильтр (2026-09-04): ложные
срабатывания на входе, переписанном без изменений (`git checkout --`, форматтер, возврат
stash'а). Правка должна убрать ложный **отрицательный**, не вернув ложный положительный.

**Критерий успеха.** Сценарий: вход из `covers:` изменён по содержанию, синтез переписан
позже входа с тем же содержимым ⇒ `--drift` **называет** этот вход. Обратный сценарий:
вход переписан без изменения содержимого ⇒ `--drift` молчит, как сейчас.

## Текущая модель

**Наблюдение (2026-09-22, `Basis: observed`).** Последовательность в этом репозитории:

1. Изменены `plugins/vdm/scripts/crystal-lint.sh`, `crystal-completion-guard.py`, добавлен
   `tests/symlink-scope.test.sh` — всё внутри `covers:` документа `docs/model/suite.md`.
2. `distill-scan.sh --drift` назвал `docs/model/suite.md` и перечислил три входа.
3. Скрипт переписал `suite.md` **идентичным** содержимым (замена по несуществующему якорю →
   no-op, но `open(…, "w")` файл всё равно перезаписал).
4. `distill-scan.sh --drift` — **тишина**. `git status` при этом показывает `suite.md`
   неизменённым, а три входа — изменёнными.

**Механизм — по коду, не по догадке.** `_files_under <dir> <reference>` отбирает файлы
условием `[ "$f" -nt "$ref" ]`, где `$ref` — сам файл синтеза (`plugins/vdm/scripts/distill-scan.sh`,
`newer_inputs`). Если синтез переписан позже всех входов, множество кандидатов пусто, и
контент-фильтр (`_content_filter_init`) до вердикта **не доходит** — ему нечего подтверждать
или отбрасывать. Комментарий в самом скрипте описывает mtime честно («every gesture that
rewrites a file without changing it moves mtime»), но выводит из этого только риск ложного
**срабатывания**; обратная сторона — что тем же жестом сигнал выключается — не названа.

**Почему это важнее, чем выглядит.** `docs-distill` прямым текстом запрещает: «Чего делать
нельзя: `touch`'ать документ или править его косметически, чтобы заглушить сигнал… Сигнал,
который позволено погасить не глядя, сигналом не является». Правило написано для человека и
опирается на его намерение. Здесь тот же эффект достигается **без намерения**: сохранение из
редактора, форматтер, скрипт, автоматическая правка фронтматтера. Запрет есть, механизма нет.

**Починено 2026-09-22 (vdm 2.29.2).** Кандидаты — и есть множество изменившихся по
содержанию, там где контент-фильтр вооружён; mtime остался запасным путём для не-git
проекта, неотслеживаемого синтеза и синтеза с незакоммиченной правкой (тогда его
собственный mtime и есть честная опора, потому что git не знает, что та правка уже
покрыла).

**Замер, как и требовал план, сделан до и после** на самом большом `covers:` этого
репозитория (14 записей, 88 файлов под покрытыми каталогами):

| Версия | `--drift-all` |
|---|---|
| до починки (mtime отбирает) | 0.47 с |
| после, наивно (`printf \| grep -Fxq` на файл) | 0.77 с |
| после, с встроенной проверкой членства | **0.46 с** |

Три вызова git в `_content_filter_init` делались и раньше, и их стоимость не зависит от
числа кандидатов — платить было не за что. Промежуточные 0.77 с целиком объясняются двумя
форками на файл; замена на `case` по строке с разделителями вернула базовую цену.

## Decision Log

### #1 / 2026-09-22 / Заведён кристаллом, а не побегом: у дефекта есть собственный критерий приёмки

**Source:** assistant
**Basis:** observed
**Basis-detail:** последовательность из четырёх шагов выше, наблюдённая в этой же сессии;
механизм подтверждён чтением `_files_under` и `_content_filter_init`.
**Context:** альтернатива — записать побегом в кристалл `docs-distill` (он в паузе) и
вернуться когда-нибудь.
**Why:** побег — симптом с гипотезой; здесь механизм уже установлен, и у починки есть
проверяемый критерий в обе стороны. Плюс правка задевает сигнал, которым пользуются все
механизмы суиты, — такое не делают между делом.
**Implication:** `ready`, singleton не занят. Приоритет — решение владельца: сегодня сигнал
работает во всех случаях, кроме того, где синтез трогали позже входов.
