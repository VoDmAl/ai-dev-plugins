# Публичный репозиторий без чужих данных: чистка дерева, перепись истории, гард против PII

> Повод — сверка 2026-10-01/02 по записке владельца `published-references-third-party` (intercom-хранилище, вне
> репо). Репозиторий публичный, а в нём лежат фамилии реальных людей, ключи задач рабочих трекеров, имена агентов,
> а в метаданных коммитов — рабочий адрес. **Этот файл сам публичный**: здесь только пути, числа и роли; точные
> списки — в приватной записке.

## Назначение

**Цель.** В публичном репозитории и во всей его истории нет:
1. имён и фамилий реальных людей;
2. ключей задач и других идентификаторов рабочих систем;
3. имён конкретных агентов — где для логики взаимодействия важна роль, она так и называется: штаб, программа,
   командный центр, слой доступа;
4. рабочего адреса в метаданных коммитов.

Плагин нейтрален: примеры вымышленные (Петров, John Doe, `PROJ-123`, `example.com`), любой агент может оказаться на
любой роли. И это держит системный гард, а не память.

**Ограничения.** Перепись истории необратима для публичного репозитория: новые хеши у всех коммитов, force-push на оба
remote, и это делает владелец. Список замен в репо не попадает — иначе он сам публикация. Хеш-ссылки в письмах агентов
(вне репо) останутся старыми — принято владельцем (DL #1).

**Критерий успеха.** Детектор этого кристалла по всей переписанной истории даёт ноль находок на эталоне сверки;
новый коммит с такими данными гард не пропускает; в метаданных один автор — `Dmitry Vorobyev <dmitry@vorobyev.org>`.
