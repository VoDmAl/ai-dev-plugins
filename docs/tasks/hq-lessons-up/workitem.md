# Общий слой правил доходит до сессий, уроки штабов поднимаются выше

> Два письма 2026-10-07: штаб (`vdm-layer-delivery`) — общий слой не доходит до сессий, и просьба о поле класса в
> памяти, хуке и ветке learn; echelon (`hq-lessons-scope`) — предложение контракта поля, ответ к 10.10. Оба —
> продолжение письма `echelon/hq-lessons-up` о схеме подъёма уроков, которую владелец принял 07.10.

## Назначение

**Цель.** Общий слой правил (`~/.claude/vdm/rules.md`) доходит до каждой сессии целиком в той форме, которую харнесс
кладёт в контекст. Процедурные уроки штабов получают класс при записи и путь наверх, а не остаются в памяти одного
проекта. Слово владельца, которое к этому привело (07.10, штабу): «Твоя память по процедурным вещам которые полезны
другим HQ не может быть твой только. Это должно идти выше в эшелон или в vdm skills. Как мы это обеспечим
системно?»

**Ограничения.** Здесь — код vdm: хук доставки слоя, хук на запись в память, `/vdm:learn`. Сбор уроков по всем
штабам и выбор дома — echelon: это утверждение о многих репозиториях, у плагина нет момента его выполнить. Какой
проект штаб, знает слой доступа (`hq <root>`), плагин спрашивает его, а не хранит. Контракт поля один на двоих с
echelon.

**Критерий успеха.** Вывод хука слоя ниже порога харнесса в каждой сессии и содержит правило каждой записи; бюджет
проверяется при записи правила и при загрузке. Запись в память штаба без класса получает напоминание. Контракт поля
согласован с echelon до 2026-10-10.

## Текущая модель

Замеры 2026-10-07:

- `rules.md` — 16 323 символа (16 918 байт), 12 правил и вступление 750 символов. Заголовки с первыми абзацами всех
  правил — 5 717 символов, только заголовки — 646.
- `plugins/vdm/scripts/shared-rules.sh` несёт `MAX_BYTES=12288` и обрезает по строкам: пять правил с конца не доходят
  ни до одной сессии, хук печатает «⚠ Truncated».
- **Порог харнесса — около 10 000 символов, не байт.** По всем транскриптам этой машины (`hook_success` в
  `~/.claude/projects/*/*.jsonl`): текстовый вывод SessionStart и UserPromptSubmit длиннее него харнесс сохраняет в
  файл, а в контекст кладёт превью первых 2 КБ. Самый длинный вывод, дошедший целиком, — 9 793 символа; самый
  короткий спрятанный — 10 017. Для JSON-вывода (`additionalContext`) больших образцов нет — порог не измерен.
- **Слой не доходил неделю.** 1 034 старта сессии с 2026-09-30 по 2026-10-07: вывод `shared-rules.sh` спрятан в файл,
  до сессии дошли шапка и начало первого правила. Сессия, в которой заведён этот кристалл, — одна из них. У штаба
  последствие видно: правило «файл в чате — ссылкой с путём» он 07.10 нарушал, потому что не видел его.
- Предложение echelon для поля: `scope: project | hq | conduct` рядом с `type`; `shared: <дом>` — куда урок поднят,
  тогда локальная запись — указатель и сбор её пропускает; память штабов лежит в `.claude/memory/` проекта и в
  `~/.claude/projects/<проект>/memory/`, сбор читает оба места. В формате памяти Claude Code `type` лежит под
  `metadata:` — где `scope` в таком файле, не решено.

## Decision Log

### #1 / 2026-10-07 / Всегда загружаются заголовок и первый абзац каждого правила

**Source:** user
**Basis:** user-stated
**Basis-detail:** владелец выбрал «Заголовок + первый абзац» из трёх кандидатов (ещё: только заголовки; полный текст с
бюджетом в символах). Цифры перед выбором — в «Текущей модели», замерены, а не прикинуты.
**Context:** слой длиннее порога харнесса; доставить весь текст можно только сократив файл вдвое.
**Why:** первый абзац правила и есть правило; обоснование, таблицы и полевые случаи нужны, когда правило применяют, и
лежат по пути к файлу. Отдельного файла-выжимки нет — нечему расходиться с источником. Только заголовки превратили бы
слой в оглавление, которое никто не открывает.
**Implication:** авторский контракт `rules.md`: первый абзац правила — само правило, коротко. Хук собирает заголовки и
первые абзацы, называет путь к полному тексту, держит бюджет в символах ниже порога и говорит, когда бюджет превышен.
`/vdm:learn` проверяет бюджет при записи правила.

### #2 / 2026-10-07 / Один кристалл на доставку, поле класса, хук и learn

**Source:** user
**Basis:** user-stated
**Basis-detail:** владелец выбрал «Кристалл на всё» против «сейчас только доставка».
**Context:** доставка чинится сразу; поле, хук и ветка learn зависят от контракта с echelon.
**Why:** четыре части — одна схема из письма `echelon/hq-lessons-up`; решения по полю меняют и хук, и learn.
**Implication:** доставка — первым коммитом; остальное — после ответа echelon по контракту.

### #3 / 2026-10-07 / Хук на запись в память — во всех проектах

**Source:** user
**Basis:** user-stated
**Basis-detail:** владелец выбрал «Во всех проектах» против «Только в штабах».
**Context:** память есть в 35 проектах (1 273 записи, замер 2026-10-07 — «Текущая модель»), штабов среди них
несколько. Узнать, штаб ли проект, можно только вызовом слоя доступа (`hq <root>`).
**Why:** урок о поведении ассистента (`conduct`) рождается в любом проекте, и только во всех проектах он получает
класс и попадает в сбор echelon. Напоминание звучит лишь на записи файла памяти без класса — событие редкое, а
вызов чужого инструмента на каждой записи был бы ценой и зависимостью.
**Implication:** хук не спрашивает, штаб ли проект. Старые записи не трогаются: напоминание — только на новую или
правленую запись; строка при старте сессии считает лишь `hq` и `conduct` без `shared`.

### #4 / 2026-10-07 / Контракт поля: значения echelon, место — рядом с `type`, где бы он ни лежал

**Source:** assistant
**Basis:** observed
**Basis-detail:** замер по `~/AI Projects/*/.claude/memory/` и `~/.claude/projects/*/memory/`, 2026-10-07: `type`
вверху frontmatter — 99 и 364 записи, под `metadata:` — 333 и 449; `scope` уже у трёх записей. Скрипт замера не
сохранён — повторяется одним проходом по frontmatter.
**Context:** echelon предложил `scope: project | hq | conduct` и `shared: <дом>` «рядом с `type`», память в двух
местах, и просил подтвердить или поправить к 10.10.
**Why:** имена и значения принимаются как есть. Поправка одна: «рядом с `type`» в половине файлов значит «под
`metadata:`» — так пишет память Claude Code. Требовать верхний уровень значило бы переписывать формат харнесса.
**Implication:** хук и сбор читают `scope` и `shared` на верхнем уровне и под `metadata:`; `MEMORY.md` — индекс, не
запись. `shared` — одна строка с адресом дома (`rules.md` → заголовок правила, `<плагин>:<скил> §…`, раздел README
echelon); непустое значение значит «поднято».
