# Дополнительный прогон (ассистент, та же лаборатория): как вернуть
# оба пути переименования — гипотеза --no-renames.

=== staged rename (git mv a.txt a-renamed.txt), четыре способа ===
  --- --name-only -z              : a-renamed.txt|
  --- --name-only -z --no-renames : a-renamed.txt|a.txt|
  --- --name-status -z            : R100|a.txt|a-renamed.txt|
  --- --name-status -z --no-renames: A|a-renamed.txt|D|a.txt|

# Вывод: --no-renames возвращает обе стороны переименования.
