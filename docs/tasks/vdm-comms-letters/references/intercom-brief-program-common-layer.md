### 2. `vdm-comms`: полная форма обязательства в `comms.pending`

Решение 7. Нужна форма, которая держит модель executor, а не сводит её к `⏰`:
- **кто двигает сейчас** — не тот, кого просим. Просьба чужая только после его подтверждения;
- **состояние**: `ask` — не отправлено, `sent` — ушло, ждём, `ack` — подтвердил; закрыто — `[x]`, по факту дела, а не по факту передачи;
- **срок** — обязателен, и **сколько раз напоминали**;
- **трек** — ссылка, где живёт дело.

Источник модели: `~/AI Projects/program/CLAUDE.md`, правила 1.1–1.4; живой пример — `dashboard.md` там же (поля `[who::] [state::] [due::] [nudges::] [track::]`, Dataview); чтение — `scripts/queue.py`. Синтаксис выбираешь ты. Требование одно: форма полная, одна на всех, старый `⏰` читается на время перехода. После этого мы мигрируем executor, а command-center и hq получат бриф.
