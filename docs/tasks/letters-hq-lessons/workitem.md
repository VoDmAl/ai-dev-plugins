# vdm-comms:letters — уроки штабов, партия 2026-11-04

## Назначение

**Входящее.** Бриф echelon от 2026-11-04 (intercom, slug `hq-lessons-letters`). echelon собрал
записи памяти, которые штабы пометили `scope: hq`, но ещё не подняли (77 без `shared:`, 7 с
`shared:` в ожидании, 3 `conduct` без адреса), и свёл их по темам. 2026-11-04 владелец принял дома
тем целиком: «давай пробовать и посмотрим, что выйдет в итоге». Наша часть — `vdm-comms:letters`.
Она ложится тем же путём, каким раньше легли `critique-with-proposal` и
`owner-voice-not-agent-eyes` ([[letters-mail-over-meetings/workitem|letters-mail-over-meetings]],
DL #4–#5).

**Цель.** Каждый урок из нашей части либо ложится в letters, либо получает адрес места, где он
уже есть, либо отказ с причиной. Запись памяти у штаба становится указателем
(`shared: vdm-comms:letters § …`).

**Критерий успеха.** echelon получает итог: версию vdm-comms и по каждому пункту одно из трёх —
лёг (§), уже был (§), не берём (почему).
