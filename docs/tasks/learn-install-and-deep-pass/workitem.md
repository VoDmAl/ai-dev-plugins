# /vdm:learn: свёрнутый урок ставить без вопроса, у потолка — глубокий проход; первый проход — сейчас

> который читают все сессии обеих машин, — это работа основной сессии с владельцем, не сессии intercom.

## Назначение

**Входящее.**
1. `learn-install-without-asking` (штаб `hq`, 2026-11-18). Слова владельца в его focused-сессии, дословно по письму:
   «Вообещ давай будем актвинее ставить - у нас же есть процедура когда превышаем - запускаем сессию по улучшение
   или увеличению границы. Передай агенту про это чтобы подправил.» Случай: урок свёрнут субагентом,
   `rules-write.py --diff` вернул 1 (расширено одно правило, заголовки целы); по шагу 3 сессия показала diff и
   спросила «ставить?», назвав цену (8 499 → 8 898 из 9 000). Владелец ответил «Ставить» и следом — словами выше.
   Срок пересмотра поставил штаб: 2026-11-25.
2. `rules-deep-pass-due-2026-11-18` (тот же штаб): после этой установки слой — 8 898 из 9 000, проход по шагу 6.
3. `rules-deep-pass-due-1119` (штаб другого проекта, 2026-11-19): по слову владельца «да» правка правила «Make the
   moves your tools reach…» (проверка на бота — открыть то же место там, где пользователь пройдёт её раз); после
   неё 8 973 из 9 000, 17 правил. Следующий лёгкий урок без ужатия не войдёт.

Кроме того, в слое ждёт места текст, на который владелец сказал «да» 17.11 (правило «Name each thing…», +238 байт)
— [[owner-ask-items-named/workitem|owner-ask-items-named]].

**Цель.** (1) Шаг 3 `/vdm:learn`: exit 1 — ставить сразу (шаг 4), diff и причину показывать владельцу после
установки, отчётом; близость к потолку и exit 5 — повод для шага 6, а не вопрос. (2) Глубокий проход по слою и по
ждущим записям `conduct` всех проектов — так, чтобы ждущий текст вошёл и осталось место для следующих лёгких уроков.

**Ограничения.** Вопрос остаётся там, где его решит владелец; кандидат из письма — слияние, убирающее заголовок, после
которого указатели `shared:` в памяти проектов осиротеют (случай 22.10: владелец выбрал прежние заголовки). Проход
ставится через `rules-write.py`, никогда правкой файла; файл синхронизирует Syncthing — `syncthing-caught-up` до
установки.

**Критерий успеха.** Новый текст шага 3 и шага 6 в learn выпущен; слой после прохода заметно ниже 8 100 байт, ждущий
текст `owner-ask-items-named` в нём; замер ушёл обоим штабам.
