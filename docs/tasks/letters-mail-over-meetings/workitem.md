# vdm-comms:letters — шаг после письма: письмо — основной канал, встреча — с тем, кто ответил

> Заведён сессией intercom 2026-10-28 по письму echelon `letters-mail-over-meetings`. Это урок
> штаба того же дня, который echelon поднял в общий слой. Тем же вечером владелец урок уточнил, и
> echelon прислал письмо `letters-mail-over-meetings-refined`; кристалл переписан под него (DL #2).
> Третье и последнее письмо урока, `letters-urgent-slot-move-own` — о времени встречи (DL #3).
> На него echelon ответил итогом: поиск окна — у него, признак заглушки опровергнут (DL #4).
> Работа — для основной сессии владельца: письма в архиве `_done/`, ответ echelon — в Next actions.

## Назначение

**Цель.** Чтобы черновик исходящего текста не выбирал следующим шагом встречу по привычке и не
расширял её состав сам. Основной канал — письмо. Встречу с тем, кто ответил, предложить владельцу
над текстом можно. Расширить круг — только по слову владельца, даже когда адресат сам предложил
собраться шире: чужое «соберёмся шире» — не повод звать остальных.

**Полевой случай** (штаб, 2026-10-28; пересказ, имена опущены). Контакт внешнего партнёра
согласился встретиться вместе с двумя другими людьми. Штаб написал в черновике ответа от имени
владельца «Встречу поставлю». Владелец: «Встречу поставлю — не надо», с одним из участников
встречу не поставить: он занят, и владелец тоже. «Встреч меньше — дел больше. Почта отличный
способ».

Тем же вечером владелец перечитал ветку целиком и уточнил: встретиться только с ответившим —
нормально, «зачем туда тащить всех?»; «давай письмом — но встречу можно завести». Ошибка была не
во встрече, а в составе. Встречу вчетвером штаб вывел из слов адресата об объединении двух этапов,
прочитанных буквально, и владельца не спросил.

Третий урок того же дня — о времени. Для встречи с одним ответившим штаб предложил ближайшее
общее свободное окно, через шесть дней. Владелец: каждый день должен быть прогресс, а звонок —
через неделю; подвинь или отмени что-нибудь моё. Для срочного трека окно ищут по занятости
собеседника, а встречи владельца, которые можно сдвинуть, считают свободным временем. Ближайшее
общее свободное окно — ответ для обычного дела.

**Критерий успеха.** Пункт § 4 `plugins/vdm-comms/skills/letters/SKILL.md` о шаге после просьбы и
сжатый чек-лист черновика (`plugins/vdm-comms/scripts/comms_checklist.py`) задают вопрос: шаг после
письма — встреча? Кто в ней, кроме ответившего? Каждого назвал владелец? Если нет — владельцу
предлагается встреча с одним ответившим или письмо. Предложенная встреча называет время; на
срочном треке — и что из встреч владельца ради него подвинуть (DL #3).
